= PostgreSQL connector upgrades and rollback
:toc:

== Before upgrading

Back up the current plugin, configuration, Kafka Connect source offsets, and replication slot state.
Check that the target version supports the existing offset format and the event format used by consumers.

== Upgrading

. Stop the connector and wait for `STOPPED`.
. Record the final offsets and `confirmed_flush_lsn`.
. Install the same plugin version on every worker. Keep the connector name, slot, publication, and `topic.prefix`.
. Restart the workers and resume the connector. Check task status, verify sample events, and confirm LSN progress.

== Rolling back

Use the previous version if it can read the offsets written by the current version.
Stop the connector, restore the previous plugin and configuration, and repeat the verification steps.
If the offset format is incompatible or the required WAL is unavailable, follow a separate recovery or migration procedure.
